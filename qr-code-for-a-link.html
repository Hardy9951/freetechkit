How to make a QR code for a link

Turn a website URL into a downloadable QR code and test it before sharing or printing.

Open the QR code generator

Make and test your QR code

Copy the full destination URL, including https://. Paste it into the QR generator, choose an image size, and select Generate QR. Scan the result with a phone and check the page that opens before downloading the PNG.

Prepare the image for printing

Keep a clear border around the code and use a dark code on a light background. Print one copy at the final size and scan it from the distance your readers will use. Test the destination over mobile data if people will scan the code away from Wi-Fi.

Choose a link you can keep

The QR image encodes the URL you enter. If you change or remove that URL later, printed copies still point to the old address. For long-lived materials, use an address you control and can redirect if the destination changes.
