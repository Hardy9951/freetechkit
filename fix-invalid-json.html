How to find and fix invalid JSON

Find common JSON syntax errors, then validate, format, or minify your corrected data.

Open the JSON formatter

Fix common syntax errors

Use double quotes for object keys and string values. Remove trailing commas after the final item in an object or array. JSON also requires lowercase true, false, and null, and it does not allow comments.

Check brackets and escaped characters

Match each opening brace or square bracket with its closing partner. Inside a string, escape embedded double quotes with a backslash and use the escape sequence for a newline instead of a literal line break.

Validate before you format

Paste the corrected text into the formatter and select Format JSON. If it reports an error near a position, inspect the characters just before that point. Use Minify JSON when you need compact output for an API request or configuration field.
